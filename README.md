# Portfolio de Maha El Yamni

Portfolio personnel : étudiante ingénieure en Intelligence Artificielle & Data Science (EMSI Rabat), à la recherche d'un stage PFE de 6 mois à partir de février 2027.

## Technologies

- Next.js 15 (App Router) et TypeScript
- Tailwind CSS 4
- Framer Motion pour les animations
- Hébergement sur Vercel

## Lancer en local

```bash
npm install
npm run dev
```

Le site est disponible sur http://localhost:3000.

## Modifier le contenu

Tout le texte du site (français et anglais), les projets, les expériences et les compétences se trouvent dans un seul fichier : `src/content.ts`. Les photos sont dans `public/images` et le CV dans `public/cv`.
